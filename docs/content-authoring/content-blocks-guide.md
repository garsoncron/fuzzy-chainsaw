# Content Blocks Guide - Cowtown Showdown CMS

This guide explains how to create and manage content pages using the Payload CMS blocks system for the Cowtown Showdown tournament website.

## Overview

The Cowtown Showdown CMS uses a flexible block-based content system that allows you to build pages by combining different content blocks. Each block serves a specific purpose and can be customized with your content.

## Available Content Blocks

### 1. Tournament Information Block

**Purpose:** Display key tournament information with statistics and highlights.

**When to use:** 
- About page
- Tournament overview sections
- Key facts and statistics

**Fields:**
- **Title:** Main heading (e.g., "About the Cowtown Showdown")
- **Description:** Brief overview text
- **Statistics:** Number/label pairs (e.g., "8 Teams", "3 Days")
- **Highlights:** Key features with icons and descriptions

**Example Configuration:**
- Title: "About the Cowtown Showdown" 
- Description: "The premier Senior Men's box lacrosse tournament in Calgary..."
- Stats: "8 Teams", "22 Games", "3 Days", "5 Point System"
- Highlights: Championship Format, Live Scoring, Western Hospitality

### 2. Rules Block

**Purpose:** Display tournament rules organized by category.

**When to use:**
- Rules page
- Penalty information
- Game format explanations

**Fields:**
- **Title:** Main heading (e.g., "RMLL Modified Rules")
- **Subtitle:** Optional description
- **Rule Categories:** Organized groups of rules
- **Additional Info:** Extra notes or clarifications

**Example Configuration:**
- Title: "Tournament Rules"
- Categories: "Game Format", "Playing Rules", "Scoring System", "Penalties"
- Each category contains numbered rules

### 3. Call to Action Block

**Purpose:** Encourage user action with prominent text and buttons.

**When to use:**
- Team registration prompts
- Contact information
- Important announcements

**Fields:**
- **Rich Text:** Formatted content with headings
- **Links:** Up to 2 buttons with different styles

### 4. Content Block

**Purpose:** General rich text content with formatting.

**When to use:**
- General information pages
- Detailed explanations
- Text-heavy content

**Fields:**
- **Rich Text:** Full WYSIWYG editor with headings, lists, links

### 5. Media Block

**Purpose:** Display images, videos, or other media.

**When to use:**
- Photo galleries
- Tournament venue images
- Sponsor logos

**Fields:**
- **Media:** Upload or select existing media files

## Creating a New Page

### Step 1: Navigate to Pages
1. Log into the Payload CMS admin panel
2. Click "Pages" in the main navigation
3. Click "Create New" button

### Step 2: Basic Page Setup
1. **Title:** Enter the page title (appears in browser tab)
2. **Slug:** URL path (auto-generated from title, can be customized)

### Step 3: Configure Hero Section
1. Click the "Hero" tab
2. Choose hero type (basic, detailed, or none)
3. Add hero content, background image, etc.

### Step 4: Add Content Blocks
1. Click the "Content" tab
2. Click "Add Block" to choose block type
3. Configure each block with your content
4. Reorder blocks by dragging
5. Use "Preview" to see how it looks

### Step 5: SEO Optimization
1. Click the "SEO" tab
2. **Meta Title:** Page title for search engines
3. **Meta Description:** Summary for search results
4. **Meta Image:** Image for social media sharing

### Step 6: Publish
1. Set "Published At" date (sidebar)
2. Click "Save Draft" or "Publish"

## Content Best Practices

### Writing Guidelines
- **Clear Headings:** Use descriptive headings for easy scanning
- **Concise Text:** Keep paragraphs short and focused
- **Tournament Terms:** Use consistent lacrosse terminology
- **Western Theme:** Incorporate Calgary/western references appropriately

### Image Guidelines
- **File Size:** Optimize images (under 1MB recommended)
- **Dimensions:** Use high-resolution images that scale well
- **Alt Text:** Add descriptive alt text for accessibility
- **Branding:** Use team colors (#934F25, #5E2713, #D6AC4D)

### SEO Best Practices
- **Unique Titles:** Each page should have a unique, descriptive title
- **Meta Descriptions:** 150-160 characters, include key terms
- **Keywords:** Include relevant lacrosse and tournament terms
- **Internal Links:** Link between related pages

## Managing Media

### Uploading Media
1. Go to "Media" collection
2. Click "Upload" or drag files
3. Add alt text and caption
4. Organize in folders if needed

### Using Media in Blocks
1. Click media field in any block
2. Choose "Upload New" or "Choose Existing"
3. Select appropriate image size/crop

## Troubleshooting

### Common Issues

**Block not appearing:** 
- Check if page is published
- Verify block configuration is complete
- Clear browser cache

**Images not loading:**
- Check file size (should be under 10MB)
- Verify file format (JPG, PNG, WebP supported)
- Ensure alt text is added

**Page not found:**
- Check slug is correct and doesn't conflict
- Verify page is published
- Check for typos in URL
